# ImpactTrack — README Explanation Draft

## In plain language

A prototype data model for showing how charitable causes, funding targets, donations and progress updates could be recorded transparently.

## Current status

The repository contains example cause records and a draft data schema. It does not take payments or verify real-world funding.

## Technical explanation

The current repository contains illustrative causes.json records and a draft schema. No payment gateway, database, donation transaction processor or verified beneficiary workflow is included. Any progress figures are sample data and should not be presented as audited fundraising results.

Document entities for Cause, Donation, Update and Verification; define currency, timezone, timestamps, evidence URL, reviewer and correction history. Explain how the progress ratio is calculated and what is excluded.

## Trust and safety

Do not show illustrative sample totals as donations received. Any real beneficiary, transaction or impact statement requires lawful evidence and independent verification. Payment handling requires a separate security/legal review.
