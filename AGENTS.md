# Agent Instructions — ImpactTrack

Read README.md, CONTRIBUTING.md and FEATURE_UPGRADE_PLAN.md first.

- Never invent causes, beneficiaries, donations, payments or impact outcomes.
- Keep sample data explicitly illustrative.
- Distinguish target, pledge, received donation and verified expenditure.
- Preserve currency, timezone, date and source provenance.
- Do not implement payment processing or collect financial/personal data without a reviewed scope.
- Add schema and arithmetic tests; work on a branch and open a PR.
