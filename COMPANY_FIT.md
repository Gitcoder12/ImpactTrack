# ImpactTrack — Company and Team Fit

Potential skills fit only; no company is known to use or endorse this prototype.

## Project thesis

A prototype data model for showing how charitable causes, funding targets, donations and progress updates could be recorded transparently.

## Microsoft

**Relevant public technical areas:** Data platforms, transparency and civic applications.

**Potential roles:** Data Engineer, Full-stack Engineer, Analytics Engineer, Data Governance Engineer or Product Engineer.

**Evidence to build:** The current repository contains illustrative causes.json records and a draft schema. No payment gateway, database, donation transaction processor or verified beneficiary workflow is included. Any progress figures are sample data and should not be presented as audited fundraising results.
